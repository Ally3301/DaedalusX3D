# Releases — DaedalusX3D (Old 3DS)

🌐 **English** | [Português (Brasil)](../README.pt-BR.md)

This directory holds staged build outputs for GitHub **Releases** (`.3dsx` and `.cia` binaries are gitignored to keep the repository clean).

## Release Files

| File | Purpose | SD Card Location |
| :--- | :--- | :--- |
| `DaedalusX64.3dsx` | Homebrew Launcher (Rosalina / HBL) | `sdmc:/3ds/DaedalusX64/DaedalusX64.3dsx` |
| `DaedalusX64.cia` | Home Menu installation (FBI) | Anywhere on SD → install with **FBI** |

> **Audio prerequisite:** Make sure `sdmc:/3ds/dspfirm.cdc` is present on your SD card (dumped via **DSP1** or Rosalina).
>
> **ROMs folder:** Place your N64 ROMs (`.z64`, `.n64`, `.v64`) in `sdmc:/3ds/DaedalusX64/Roms/`.
